# KCIB

ระบบจองเครื่องมือ ภาควิชาวิศวกรรมเคมี สจล. หน้าเว็บอยู่ใน `index.html`, `css/` และ `js/`

## กติกาการจอง

- ทุกหมวดจองล่วงหน้าอย่างน้อย 3 วันทำการ โดยไม่นับวันปัจจุบัน เสาร์–อาทิตย์ และวันหยุดจากชีต Holidays ตามเวลาไทย
- เวลาใช้งาน 09:00–16:00 น. ช่วงเวลาปกติเลือกได้ 1, 2 หรือ 3 ชั่วโมง
- เตาเผา เตาอบ HPLC GC เครื่องแก้ว และอุปกรณ์วิทยาศาสตร์ระบุวัน/เวลาเริ่มและสิ้นสุดเองได้
- อาจารย์ที่ปรึกษา → หัวหน้าภาคอนุมัติ จบขั้นตอนการอนุมัติ เจ้าหน้าที่ดูรายการและสถานะได้โดยไม่ต้องกดรับทราบ
- ผู้มีหลายบทบาทสลับได้เฉพาะบทบาทใน StaffConfig การอนุมัติตรวจบัญชี Google และสิทธิ์ซ้ำที่เซิร์ฟเวอร์
- รายการสถานะเดิม “รออนุมัติขั้นที่ 3” แสดงเป็น “อนุมัติแล้ว” โดยไม่แก้ประวัติในชีต และไม่นับเป็นรายการรอดำเนินการ

## ตรวจสอบ

ข้อมูลเริ่มต้นสำหรับแสดงรายการมี cache ฝั่ง Apps Script 60 วินาที ปุ่มรีเฟรชข้าม cache นี้ การจองและการอนุมัติอ่านข้อมูลและสิทธิ์จากชีตล่าสุดเสมอ

การอนุมัติ/ปฏิเสธส่งแถวที่อัปเดตกลับมาให้หน้าเว็บใช้ต่อโดยไม่โหลดตารางซ้ำ คำสั่งทั้งหมดส่งเป็นชุดละไม่เกิน 200 รายการ และรายงานรายการที่สำเร็จหรือไม่สำเร็จแยกกัน

```sh
node --test tests/booking-rules.test.cjs
```

## Apps Script

ใช้ `code.gs` เป็น backend หลัก และ `js/booking-rules.js` เป็นกติกาที่ใช้ร่วมกับหน้าเว็บ ต้อง deploy ทั้งสองไฟล์พร้อมกัน ผ่าน `.clasp.json` เดิม

`.claspignore` จำกัดไฟล์ที่ส่งไว้เป็น `code.gs`, `js/booking-rules.js` และ `appsscript.json` เท่านั้น ไฟล์เก่า `code.js` และ `code.gs.temp` ไม่ใช่ไฟล์สำหรับ deploy

บัญชีผู้ deploy ต้องเปิด Google Apps Script API ที่ https://script.google.com/home/usersettings ก่อนอัปโหลด

```sh
clasp status
clasp push
clasp deploy --deploymentId <deployment-id-เดิม> --description "Booking rules and staff viewing"
```

คอลัมน์รับทราบเดิม `StaffAcknowledgedAt` และ `StaffAcknowledgedBy` เก็บไว้เป็นประวัติ ระบบไม่เขียนข้อมูลรับทราบเพิ่ม ชื่อบทบาทและรายชื่อสมาชิกอยู่ใน StaffConfig

หน้าเว็บ deploy ผ่าน GitHub Pages เมื่อ push เข้า `main` ธีมและบทบาทที่เลือกล่าสุดบันทึกเฉพาะในเบราว์เซอร์
